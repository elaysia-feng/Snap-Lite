# Snap-Lite v1.3.3-beta.9

Beta test focus — fix the visible "flash" on every keystroke inside a text annotation:

- Text input no longer flashes between keystrokes. The previous `ResizeHostToLiveText` path forced `snipHwnd` to repaint synchronously via `RedrawWindow(..., RDW_UPDATENOW)`, which BitBlts capture pixels over the EDIT before the child window composition step could restore it — that was the visible one-frame blank on every key. Switched to `InvalidateRect` so the parent repaint happens after the EDIT has already drawn and the child windows have composed; `WS_CLIPCHILDREN` already prevents the deferred parent repaint from overwriting the live text region.
- Single-line change in `src/edit_repaint_fix.h`; the layout, measure, IME, focus, and commit paths are untouched.

Release trigger: publish after deterministic PE icon verification passes in Windows x64 CI.
