# Snap-Lite v1.3.16

- 统一 Snap-Lite 自绘界面的视觉语言：浅粉白 / 奶油白、淡粉边框、樱粉强调、统一深色正文与危险操作色。
- 新增共享 `ui_theme.h`，让工具栏、OCR 结果面板、贴图菜单使用同一套颜色、圆角和字体规范。
- 彻底重做贴图右键菜单：移除旧的深蓝黑界面，改为“贴图设置”浅色圆角面板。
- 透明度区域改成独立白色卡片，使用粉色滑杆、百分比显示，并保留 Ctrl+滚轮快速调整能力。
- “复制贴图 / 另存为 / 关闭贴图”统一为圆角悬浮操作项，关闭操作使用统一柔和红色语义。
- OCR 结果面板切换为同一共享配色；截图工具栏继续保留五位角色的小按钮设计，同时统一正文/取消按钮颜色。
- Windows 原生文件选择器等系统级窗口保持系统样式，Snap-Lite 自己绘制的界面统一为同一套主题。
- v1.3.15 的 RapidOCR 本地高精度识别和双 EXE 完整包方案继续保留。
