# Snap-Lite v1.3.11

- 新增橡皮工具，保持现有紧凑二次元角色按钮风格。
- 橡皮通过恢复原始截图像素擦除栅格标注，而不是用白色覆盖。
- 橡皮支持细 / 普通 / 粗 / 很粗四档，并支持快捷键 E。
- 新增“取字”功能：使用 Windows 系统 OCR 离线识别当前截图选区，并自动复制识别文字到剪贴板。
- OCR 不调用外部网络服务；识别语言跟随 Windows 已安装的 OCR 语言包。
- Ctrl+Z 位图历史由 6 步 / 32MB 扩展为最多 128 步 / 512MB。
- 保留现有鼠标悬浮功能提示。
- 修复生成源与原始头文件重复包含导致的 Windows 编译冲突。
