# Snap-Lite v1.3.3-beta.8

Beta test focus — fix the text annotation interaction model:

- Click an existing text annotation to select it; drag with a 4 px threshold (no more "click = drag" misfires).
- Double-click committed text to re-enter edit mode.
- Text tool stays active after commit, so you can keep creating annotations without re-clicking the tool button.
- ESC layered: first ESC cancels the in-progress edit; second ESC exits the snip.
- Remove both `WS_EX_TRANSPARENT` flags on the text host and the inner EDIT so mouse / focus / IME routing is no longer bypassed.
- IME composition / candidate window now follows the caret via `ImmSetCompositionWindow` + `ImmSetCandidateWindow` (Chinese / Japanese typing inside the annotation works as expected).
- Delete the dead `SnipWindow::BeginTextEdit` / `CommitTextEdit` path that the modern toolbar shadowed; the legacy EDIT-on-snip-window code can no longer race the toolbar.
- Pull `edit_repaint_fix.h` out of the global `/FI` include and into an explicit `#include` so `SetWindowSubclass` / `RedrawWindow` only get their IME / refresh shim where it is actually needed.
- Add `imm32` to the link line for the new IME composition positioning.

Build / runtime hygiene:

- Create the text host window at its measured size on the first paint (no 80×28 flash, no out-of-bounds origin near the bottom of the selection).
- Remove the dead `EN_UPDATE` repaint branch that the macro hijack was suppressing anyway.
- `SelectText` no longer silently flips the active tool to "Select"; selecting an annotation must not steal the user's drawing / shape tool.
- `RemoveTextItem` records the undo action internally so callers cannot forget to push history.
- Pull the bake-and-preview text inset `(+4, +2)` into named `kTextInsetX` / `kTextInsetY` constants so `BuildTextOverlays` and `PaintTextItem` cannot drift.
- `MeasureText` now uses a memory DC instead of the parent's screen DC so device padding on high-DPI displays cannot bleed into text-width measurements.

Release trigger: publish after deterministic PE icon verification passes in Windows x64 CI.
