# Snap-Lite v1.7.0

新增延时截图，并继续完善 OCR、标注编辑和绘图历史。

- 托盘菜单新增 3 / 5 / 10 秒延时截图，倒计时覆盖层可点击取消；用于截取短暂出现的菜单和通知。
- OCR 改为后台识别，结果面板支持 Esc 关闭、焦点归还和复制识别文本，避免识别时阻塞界面。
- 几何标注支持复制、调整图层、键盘切换与 Shift 方向约束；选中后可直接调整样式，并统一接入撤销 / 重做。
- 改进工具栏提示、颜色名称、快捷键说明及高 DPI 下的交互反馈。
- 优化绘图历史压缩和截图缓存，修复多项撤销 / 重做、橡皮和 OCR 图像合成问题。
- 每天启动时检查 GitHub 最新正式版；发现更新时在托盘菜单提示，点击后显示更新说明、校验安装包并自动启动升级。
- 继续使用 Windows 系统 OCR，无需额外运行时依赖。

Windows 11 x64。
