# Snap-Lite v1.3.4

修复 Windows 应用图标打包。

- 根因修复：上一版 ICO 的目录尺寸与真实 PNG 图层尺寸不一致，Windows Shell 会回退为通用 EXE 图标。
- 不再使用损坏的 48/256 图层，也不再使用无法被 Windows 图像解码器正常读取的 PNG 源生成伪多尺寸 ICO。
- 从原始 ICO 中提取完整有效的 16x16 与 32x32 PNG 图层，重新构造标准 Windows ICO 并嵌入 PE。
- CI 增加 RT_GROUP_ICON / RT_ICON 元数据与 PNG 实际尺寸一致性校验。
- CI 增加 Windows 原生 ExtractIconEx 验证，确保资源管理器能够实际提取 large/small icon。
- Windows 11 x64。
