Snap-Lite v1.3.3-beta.4

Beta test focus:
- Text annotation editor now resizes from live EDIT contents so Chinese text is no longer clipped after roughly two characters.
- Removed the hide/show transparent EDIT repaint cycle that could trigger focus-loss and delete/commit the whole annotation.
- Backspace/Delete/Cut/Clear now keep native character-level editing behavior.
- Transparent editing background is restored directly from the captured bitmap during WM_ERASEBKGND.
- Caret selection is preserved while text width changes.
