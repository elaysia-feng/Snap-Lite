# Snap-Lite v1.6.0

继续完善 C++ / Win32 原生轻量版的标注交互，没有新增运行时依赖。

- Ctrl+D 复制选中的几何标注，副本自动偏移并保持在选区内，可独立移动和修改样式。
- Ctrl+Home / End 将标注置顶 / 置底，Ctrl+PageUp / PageDown 调整一层；到达最上或最下层不产生无效撤销记录。
- Tab / Shift+Tab 按顺序切换几何标注，方便选中重叠或细小对象；Esc 优先取消对象选择。
- 选中已画标注后可直接修改颜色、线宽、形状和填充，工具栏同步显示该对象的样式。
- 按住 Shift 拖动标注可锁定水平或垂直方向。
- 文字与几何标注选择互斥，避免修改文字时误改其他对象。
- 修复已提交文字改色和改字号无法正确撤销的问题，新增功能均接入统一撤销 / 重做。
- 本地 222 项真实 Win32 窗口和工具栏交互检查通过，覆盖复制、图层、样式及文字混合历史。

Windows 11 x64，继续使用 Windows 系统 OCR。
