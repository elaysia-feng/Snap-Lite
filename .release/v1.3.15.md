# Snap-Lite v1.3.15

- OCR 内核从 Windows.Media.Ocr 升级为本地 RapidOCR 3.9.2 + ONNX Runtime，默认使用 RapidOCR 随包模型，显著提升中文、小字号 Windows UI、中英文混排和文件名识别能力。
- OCR 前对小字号截图进行 2x/3x 高质量放大和轻度锐化，并额外尝试 CLAHE 灰度增强候选，自动选择质量更高的识别结果。
- 根据 OCR 检测框的 Y 坐标重新聚类视觉行，再按 X 坐标排序，同一屏幕行保持在同一文本行；较大的垂直间距继续保留为空行。
- 自动过滤低置信度结果和纯图标/纯标点误识别，减少文件图标、展开箭头等 UI 元素产生的乱码。
- 右侧粉白 OCR 结果面板保持不变，继续支持选择文字、Ctrl+C、复制选中和复制全部。
- RapidOCR 作为独立 SnapLiteOCR.exe 与主程序一起打包；主程序找不到该组件或其运行失败时会自动回退 Windows OCR。
- 从本版本开始，高精度 OCR 版本只发布完整 ZIP，请解压后保持 SnapLite.exe 与 SnapLiteOCR.exe 在同一目录运行。
