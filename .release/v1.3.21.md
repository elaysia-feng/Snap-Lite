# Snap-Lite v1.3.21

- 重做二次元编辑工具条视觉层，保留人物素材，改为统一圆角托盘和轻量悬停/选中态。
- 新增随安装包提供的本地 PaddleOCR CPU worker，优先处理中文截图文字识别。
- PaddleOCR worker 启动失败或单独运行 `SnapLite.exe` 时自动回退 Windows OCR。
- 安装包和便携 ZIP 自动携带 OCR worker、模型目录，并保留 SHA256 校验文件。
- 修复 OCR worker 输出读取代码在 MSVC 下的编译问题。
- 拆分 OCR worker 发布构建步骤，并兼容 PaddleOCR 3.x 的嵌套结果格式。
- 发布预热默认使用官方 BOS 模型源，避免模型下载受 Hugging Face 网络限制影响。
