# Snap-Lite v1.5.1

完善几何标注的键盘操作，减少误操作和图像缓冲分配。

- 选中箭头或形状后可按 Delete 删除；删除操作支持撤销和重做。
- 方向键可逐像素移动选中的几何标注，Shift＋方向键每次移动 10 像素；到达选区边缘后不再生成无效历史。
- 单击或不足 3 像素的几何绘制手势不再创建不可见对象，也不会清空重做记录。
- 绘制新形状时按 Esc 可取消当前笔画，保留原工具和历史。
- 文字背景及 OCR 取图复用整屏合成位图，刷新时重新绘制像素，避免反复分配位图及移动后的旧图残留。
- 新增键盘删除、微调、绘制取消及 GDI 资源回归，本地 197 项真实 Win32 窗口交互检查通过。

Windows 11 x64，继续使用 Windows 系统 OCR。
