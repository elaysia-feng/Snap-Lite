# Snap-Lite v1.3.14

- 重做“提取文字”结果面板：改为粉白圆角自绘界面，移除原生 Windows 标题栏和灰色按钮的旧式视觉。
- 结果区增加更舒适的内边距、中文字体、统一的圆角按钮，并保留“复制选中 / 复制全部 / 关闭”。
- OCR 不再直接使用被压平的 result.Text()，改为按 Windows OCR 的 Lines() 逐行重建文本。
- 每个识别行都会保留换行；检测到明显更大的原图行间距时，会额外保留段落空行，让结果更接近截图中的排版。
- OCR 继续使用 2x/3x 放大、原色 / 灰度增强 / 二值化和中文优先的多候选识别策略。
- 文本框取消横向滚动，长文本会自动换行；用户仍可直接鼠标拖选并 Ctrl+C 复制任意片段。
