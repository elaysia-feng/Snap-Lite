# Snap-Lite v1.3.3

正式版发布。

- 修复 Windows 可执行文件图标打包：构建时生成 16/32/48/256 多尺寸 PNG 编码 ICO，并嵌入 PE 资源。
- 兼容最新 Windows SDK `rc.exe`，避免旧式 DIB 图标导致 RC2176。
- 去除 GitHub runner 对 `System.Drawing` 的依赖，提升发版稳定性。
- 资源管理器、任务栏和托盘可按 DPI 选择合适尺寸图标。
- Windows 11 x64。

## 本次修复

- 画布中的直线、曲线、折线、阶梯箭头及箭头头部改为 GDI+ 高质量抗锯齿绘制。
- 矩形、圆形、三角形、菱形、六边形和画笔落图统一使用浮点坐标、圆角线帽与 8×8 抗锯齿。
- 保留原有轻音少女人物工具栏、Windows OCR“取字”和截图标注功能。
