# Snap-Lite v1.5.0

支持拖动全部几何标注，并改善截图选区四边的交互。

- 箭头、矩形、圆角矩形、圆圈、椭圆、直线、三角形、菱形和六边形均可移动；选中后通过控制点调整大小或端点。
- 空心形状通过边线拖动，填充形状也可通过内部拖动，保留各自颜色、线宽和填充样式。
- 选区整条边线可拖动，命中范围随 DPI 缩放；保留按下偏移、固定对边，防止跳动、翻转和选区消失。
- 几何标注接入撤销、重做、橡皮、OCR 图像合成及导出；取消拖动不会破坏重做记录。
- 修复双击标注误完成截图，以及选择工具移动标注时工具栏遗漏撤销记录的问题。
- 增加真实 Win32 窗口和工具栏交互回归，覆盖全部形状的三种填充模式。

Windows 11 x64，继续使用 Windows 系统 OCR。
