# 标注编辑快捷键

这些功能直接运行于 Snap-Lite 的 C++ / Win32 原生轻量版，适用于箭头及全部几何形状。

| 操作 | 方法 |
| --- | --- |
| 选择并移动 | 拖动边线；填充形状也可拖动内部 |
| 调整大小或端点 | 拖动选中对象的两个控制点 |
| 修改已画标注 | 选中对象后在工具栏调整颜色、线宽、形状或填充 |
| 复制标注 | Ctrl+D，副本自动偏移并选中 |
| 切换选中对象 | Tab；Shift+Tab 反向切换 |
| 取消对象选择 | Esc；拖动中按 Esc 则取消本次拖动 |
| 置于最上层 / 最下层 | Ctrl+Home / Ctrl+End |
| 上移一层 / 下移一层 | Ctrl+PageUp / Ctrl+PageDown |
| 水平或垂直拖动 | 拖动时按住 Shift，按位移较大的方向锁定 |
| 微调位置 | 方向键移动 1 像素；Shift+方向键移动 10 像素 |
| 删除选中对象 | Delete |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Y |

复制、删除、图层调整和样式修改都可撤销。几何对象之间可调整层级，文字仍显示在几何标注上方；画笔、马赛克和截图背景不参与几何对象图层排序。

选中文字后，颜色、字号和删除操作只作用于文字。对已提交文字的颜色与字号修改同样可以撤销。
